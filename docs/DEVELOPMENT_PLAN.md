# 開発計画

各フェーズは実装、対象環境でのビルド、必要なテスト、結果の記録を完了条件とする。環境が不足する場合は未検証を明記し、完了扱いにしない。

| Phase | 対象 | 主要な完了条件 |
| --- | --- | --- |
| 0 | 構成・仕様・環境・テスト・CI | 基盤チェック成功、CI実行確認、対象開発環境の準備 |
| 1 | Firebase・認証 | 認証とアカウント分離、Rulesとエミュレータテスト |
| 2 | iOS基本機能 | プロジェクト・カテゴリ・タイマー・履歴とローカル保存 |
| 3 | 同期 | 冪等再送、競合保持、オフライン復帰と重複集計の検証 |
| 4 | PC自動計測 | 常駐、操作・ロック・スリープ、放置確認と復旧 |
| 5 | IDE・ターミナル | 対応環境別の連携、判定と信頼度 |
| 6 | ブラウザ | 許可サイトとプロジェクト連携、収集範囲の検証 |
| 7 | 分析・iOS拡張 | 集計、目標、ウィジェット、Live Activities、出力 |
| 8 | 総合検証 | セキュリティ、性能、各OSでの検証と配布準備 |

プラットフォーム・実機・外部サービスに依存する検証は実際に利用できる環境で実施する。
